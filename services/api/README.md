# @channelwatch/api

CHANNELWATCH backend (Hono + Drizzle + Postgres). M1 provides the database
layer and a `GET /healthz` endpoint; the public `/api/v1` endpoints (SPEC §17)
arrive in M2.

## Layout

- `src/db/schema.ts` — Drizzle schema, SPEC §16 tables verbatim + `reviewers`.
  Enum-valued columns are TEXT; allowed values are validated at the application
  boundary via `@channelwatch/schemas` (no Postgres ENUM types).
- `src/db/client.ts` — lazy Postgres pool (no socket opened at import time).
- `src/db/mappers.ts` — pure row↔`@channelwatch/schemas` mappers.
- `src/index.ts` — Hono app (`createApp`) + `/healthz`.
- `src/server.ts` — Node entrypoint (binds a port; not imported by tests).
- `scripts/migrate.ts` — apply committed migrations.
- `scripts/seed.ts` — idempotent SPEC §35 "Example Channel" seed.
- `migrations/` — committed SQL migrations (generated by `drizzle-kit`).

## Local development with Postgres

```bash
# from the repo root
cp .env.example .env                 # DATABASE_URL for localhost:5432
docker compose up -d postgres        # start Postgres 16

pnpm --filter @channelwatch/api db:migrate   # apply migrations
pnpm --filter @channelwatch/api db:seed      # seed §35 record (idempotent)
pnpm --filter @channelwatch/api test         # unit + DB integration tests

docker compose down                  # stop Postgres when finished
```

Root aliases `pnpm db:migrate` / `pnpm db:seed` delegate to this package.

Regenerate migrations after editing `schema.ts`:

```bash
pnpm --filter @channelwatch/api db:generate
```

## Tests

- `tests/mappers.test.ts` — pure unit tests, always run (no database).
- `tests/integration.test.ts` — runs only when `DATABASE_URL` is reachable;
  otherwise it skips cleanly with a message. Migrates, seeds twice (idempotency),
  then derives `PE_BACKED` from the seeded chain via `@channelwatch/graph`.
